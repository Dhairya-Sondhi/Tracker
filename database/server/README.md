# Legacy database files

The files in this directory describe the retired MySQL deployment and are retained only for historical reference. Vlocity now uses Supabase Auth and Supabase PostgreSQL.

For the active schema and deployment instructions, use `database/supabase/001_vlocity.sql` and `docs/supabase-server-setup.md`. Do not run `provision.mysql.sql.example` for a Supabase deployment.
